# DCENIA
DCENIA (Distributed Computing on Edge Nodes for IoT Applications) implements a hybrid hardware framework that integrates an Arduino Uno, 
which serves as the IoT Sensor Layer for continuous data streaming, with a network of local edge nodes (laptops or Raspberry Pi devices). 
This network is structured on a distributed master-worker architecture where one designated Master Node manages workload partitioning, 
task assignment, and result aggregation, while multiple Worker Nodes execute parallel distributed tasks. The core objective of this system is to 
demonstrate efficient task distribution, parallel computation, and low-latency processing of sensor data streams.

> This project was completed as part of the course requirements for CS3100: Internet of Things and Edge Computing.
